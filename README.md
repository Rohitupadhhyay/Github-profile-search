# GitHub Profile Search

A simple and intuitive **React** + **Vite** web application that enables users to search for GitHub usernames and view basic profile details. Built to be lightweight, fast, and user-friendly.

---

## 🚀 Features

- Search for any GitHub username and fetch relevant profile details
- Display key user information: avatar, name, bio, followers, and more
- Redirect to the full GitHub profile with one click for deeper exploration
- Built with **React** and powered by **Vite** for lightning-fast performance

---

## 🛠️ Tech Stack

- **React** — for building the user interface  
- **Vite** — for development build and fast HMR (Hot Module Replacement)  
- **JavaScript**, **HTML**, **CSS/SCSS** — for app logic and styling
